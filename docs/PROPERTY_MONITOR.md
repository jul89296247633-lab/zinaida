# Недвижимость у воды

Добавлено 10.09.2026. Отдельные сообщения в существующий Telegram-бот.

## Охват

Москва, Московская область, Санкт-Петербург, Ленинградская область.
Квартиры с потенциалом роста цены за 3–10 млн ₽; вид — преимущество, не условие.
Участки у воды до 5 млн ₽ за весь участок. Полная цена, не первый взнос.
Карточки без цены в бюджете отклоняются. Цена «от» явно маркируется. До восьми карточек за запуск.

Источники задаются в `config/property_sources.json`: сайты Setl, ФАКТ и шесть RSS-поисков Google News. До 12 дополнительных
ссылок на тех же доменах за запуск. Это выборочный мониторинг открытых
источников, не полный реестр объявлений. Недоступность источников сообщается.

Цена по проекту не означает цену видового лота. Вид из конкретного окна,
ВРИ, ограничения строительства, подтопление и доступ к берегу требуют
отдельной проверки. Сведения продавца не равны юридической проверке.

## Запуск

Отдельный workflow `property-monitor.yml`: ежедневно 08:17 МСК, вручную
через workflow_dispatch и при изменениях его файлов в main.
Основная газета не изменена. Секреты используются существующие;
новые значения не требуются и в исходниках отсутствуют.

Стандартная библиотека Python; `python gazeta/property_monitor.py`.
`--collect-only` проверяет сбор без модели, отправки и записи истории.
`--dry-run` вызывает редактора, но не отправляет и не сохраняет историю.

## Проверки и ограничения

Редактор сравнивает текущий текст с прошлым по пять источников за запрос.
Валидируются ссылка на источник, дословная цитата, числовые токены,
длина полей; Telegram HTML экранируется. Семантическая точность не может
быть гарантирована только такими проверками; неизвестное маркируется.

История `.property-state/` не коммитится. Actions cache сохраняет снимки
публичных страниц и хеши отправленных карточек между запусками.
При удалении/вытеснении cache возможны повторы. Не гарантируется exactly-once
при обрыве между успешной отправкой Telegram и сохранением cache.
После частичной отправки повторяются только ещё не отмеченные карточки.

Локальная проверка:

```sh
python -m py_compile gazeta/property_monitor.py
python -m unittest gazeta.test_property_monitor -v
```

Семь тестов, включая границы бюджета и изоляцию ошибочной карточки: проверка источника/чисел/HTML, очистка страниц, dry-run,
частичная доставка с повтором, полный отказ источников.
Старый splitter не используется; новый модуль тестирует собственный формат.
Успех в логах: `PROPERTY_TELEGRAM_SENT`, итог `PROPERTY_DONE N`.
Исключения логируются только классом, без адресов Telegram API.
