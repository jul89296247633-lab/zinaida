# Зинаида — инструкция для пользователя

_Обновлено: 2026-08-26_

## Что это

Зинаида — ежедневный новостной дайджест. Каждое утро она собирает тренды и свежие статьи, отбирает интересное по вашим темам и присылает одно сообщение в Telegram-бот **@TrendsJulbot**.

## Как этим пользоваться

- Сообщения приходят **каждый день утром, к ~07:00 по Москве** (иногда на несколько минут позже) (обычно 1–3 сообщения подряд).
- Внутри: шапка с числом новостей, блок «Тренды по группам» (Product Hunt, GitHub Trending, Hacker News, Google Trends), блок «RSS-статьи» с выжимкой каждой статьи (OpenAI, DeepMind, Google AI Blog, Hugging Face, The Verge, VentureBeat, ZDNet, TechCrunch, Habr, vc.ru, РБК, Sostav, Hacker News) и блок «🛠 Проекты дня» — 4 самых горячих репозитория GitHub с описанием, зачем они могут быть полезны.
- Заголовки новостей — на языке источника (английский/русский); подписи и разметка — на русском.

## Что можно поменять (по просьбе агенту)

- время доставки (сейчас 07:00 МСК);
- список источников (добавить/убрать ленту);
- темы-фильтры: сейчас 8 групп, включая «Модели ИИ (релизы и обзоры)» и «Акции и цены ИИ»;
- формулировки русских подписей в сообщении.

## Ограничения и известные особенности

- Если лента-источник умирает, дайджест всё равно приходит — без неё.
- Если репозиторий 60 дней не трогать, GitHub ставит расписание на паузу — дайджест пропадёт. Лечение: любой агент включит обратно за минуту.
- Дайджест показывает только то, что совпало с вашими темами (плюс 4 проекта GitHub без фильтра): если «скучный» день, сообщение будет коротким.
- Выжимки статей берутся из описаний самих статей и обрезаются ~200 символов; это краткая аннотация, не пересказ.

## Поддержка

Напишите агенту в ZCode: «Зинаида: <проблема/пожелание>». Репозиторий: https://github.com/jul89296247633-lab/zinaida
